# M5 Result Scripts

Папка хранит контрольное состояние C#-скриптов на конец каждого урока модуля 5.

- `y1` — арбалет и стрела: `CrossbowShooter` прицеливается на мышь и стреляет, `BoltProjectile` летит вперёд и сам удаляется.
- `y2` — враг: `EnemyUnit` идёт справа налево (`Space.World`), хранит здоровье и получает урон, стрела наносит урон через trigger.
- `y3` — методы с `return`: `IsAlive()` и `CanShoot()`, база `DefensePoint` с уроном и проигрышем (`HasLost()`).
- `y4` — `GameManager`: валюта, награда за врага, улучшение урона, UI и эффект смерти (`Die()` + `deathEffectPrefab`).
- `y5` — `EnemySpawner`: спавн за экраном, случайная высота (`Random.Range`) и простые волны.
- `y6` — полный финальный набор: счёт, экран Game Over и рестарт (`SceneManager.LoadScene`), баланс и сборка.

У каждого урока свой namespace: `Lessons.M5.Y1`, `Lessons.M5.Y2` и так далее.
Так папки можно переносить в Unity для проверки без конфликта одинаковых имён классов.

Важно: если переносите конкретный урок в Unity, добавляйте компоненты из namespace этого урока.
Например, для первого урока используйте `Lessons.M5.Y1.CrossbowShooter`.
